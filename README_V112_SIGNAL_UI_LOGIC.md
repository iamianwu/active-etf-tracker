# V112 今日訊號資料邏輯與手機 UI 修正

這版修正：

1. 今日訊號只統計同一個 target date，不混入前一天資料。
2. 顯示 `已取得今日資料：X / 27 檔`，若有 ETF 未更新會明確提示。
3. 今日四張重點卡改成固定資訊層級：股價、漲跌幅、淨額、張數、買賣共識。
4. 資金交易明細改成手機友善 list，避免卡片過大與欄位擁擠。
5. 排序名稱改清楚：淨流入、淨流出、絕對金額、張數、買進ETF、賣出ETF、股價、漲跌幅。
6. 每筆交易明細可點進個股頁 `/stock/{code}`。
7. 漲停 / 跌停會以股價底色標示。

如果本機 `npm run build` 出現 `supabaseUrl is required`，代表本機沒有 `.env.local`。Vercel 有環境變數的話可以直接 push。
