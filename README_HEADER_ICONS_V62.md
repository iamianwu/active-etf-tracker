# Header icons v62

這個 patch 會把右上角的 icon 改成：

- 人頭 icon → 小鈴鐺 icon
- Search icon → 你提供的新 Search icon

檔案：
- frontend/public/icons/header-bell.svg
- frontend/public/icons/header-search.svg
- tools/apply_header_icons_v62.py

使用方式：

```bash
python3 tools/apply_header_icons_v62.py
```

然後 commit / push。
